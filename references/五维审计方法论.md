# 五维审计方法论（明清官制版）

## 概述

三审六部的核心在于**五维审计**，每道审核关卡对标的商号进行五个维度的量化评估，低于阈值即驳回。五维各有权重，少数维度权重最高可一票否决。

---

## 一审五维审计：都察院御史·机会审核

> 审核目标：判断商号入局机会是否成立
> 审核权限：第一道不可逆关卡，驳回则流程终止

### 维度一：天机趋势验证（权重25%）

**核心指标：**
- 天机MACD值 > 0（diff线在零轴上方）
- 商号价位站上天机均线50（50日均线）

**评分标准（0-5分）：**

| 评分 | 条件 |
|------|------|
| 5分 | MACD柱持续放大（>0.5）+ 价位在天机50均线上方 > 5% |
| 4分 | MACD值>0 + 价位在天机50均线上方 |
| 3分 | MACD值>0 + 价位在天机50均线附近 ±3% |
| 2分 | MACD值在零轴附近（-0.1~0.1）+ 均线纠缠 |
| 1分 | MACD值<0 + 价位在天机50均线下方 |
| 0分 | MACD柱持续放大在零轴下方 + 均线空头排列 |

**通过阈值：** 得分 ≥ 3分

**计算公式：**
```
趋势得分 = (MACD状态分 × 0.5) + (均线位置分 × 0.5)
MACD状态分：正值>0.5→5, 正值→4, 零轴附近→2, 负值→1
均线位置分：偏离>5%→5, 站上→4, ±3%→3, 附近±5%→2, 跌破>5%→1
```

---

### 维度二：量能验证（权重20%）

**核心指标：**
- 量比 > 1.2（相对于5日均量）
- 或成交额较5日均量显著放大（>1.5倍）

**评分标准（0-5分）：**

| 评分 | 条件 |
|------|------|
| 5分 | 量比 > 3.0 且 成交额放大 > 2倍 |
| 4分 | 量比 2.0~3.0 或 成交额放大 1.5~2倍 |
| 3分 | 量比 1.2~2.0 或 成交额放大 1.2~1.5倍 |
| 2分 | 量比 0.8~1.2（量能正常，但无明显放大） |
| 1分 | 量比 0.5~0.8（缩量） |
| 0分 | 量比 < 0.5（严重缩量） |

**通过阈值：** 得分 ≥ 3分

**特殊情况：**
- 次新股上市前5日：量比标准可放宽至 > 0.8
- 涨停板：量比可<1（缩量涨停反而是强势信号）
- 跌停板：任何量比均视为危险信号 → 直接0分

---

### 维度三：豪强动向验证（权重20%）

**核心指标：**
- 主力净流入（万两）> 0
- 主力净流入占比（%）> 0（相对总成交额）

**评分标准（0-5分）：**

| 评分 | 条件 |
|------|------|
| 5分 | 主力净流入 > 1亿两 + 占比 > 15% + 超大单持续买入 |
| 4分 | 主力净流入 5000万~1亿两 + 占比 10%~15% |
| 3分 | 主力净流入 1000万~5000万两 + 占比 5%~10% |
| 2分 | 主力净流入 0~1000万两 + 占比 0%~5%（微量流入） |
| 1分 | 主力净流出 0~-3000万两 |
| 0分 | 主力净流出 < -3000万两 或 占比 < -10% |

**通过阈值：** 得分 ≥ 3分

**数据来源优先级：**
1. 东方财富豪强动向（实时）→ 首选
2. 东方财富板块资金流向（辅助）
3. 5日累计豪强动向（消除单日噪音）

---

### 维度四：邸报验证（权重20%）

**核心指标：**
- 帮派（行业）景气度：帮派指数处于上升通道
- 业绩：Q1净利润同比正增长

**评分标准（0-5分）：**

| 评分 | 条件 |
|------|------|
| 5分 | 帮派指数MA20向上 + Q1净利润同比 > 30% + 有重大帮派催化 |
| 4分 | 帮派指数MA20向上 + Q1净利润同比 > 10% |
| 3分 | 帮派指数横盘 + Q1净利润同比 > 0% |
| 2分 | 帮派指数横盘 + Q1净利润同比 = 0% 或 暂无数据 |
| 1分 | 帮派指数MA20向下 + Q1净利润同比 < 0% |
| 0分 | 帮派指数大幅下跌 > 5% + 业绩亏损 |

**通过阈值：** 得分 ≥ 3分

**特殊规则：**
- 若帮派处于绝对风口（单日帮派指数涨停），邸报验证可降分通过（≥2分）
- 若无最新一季报数据：按"数据缺失"处理，邸报验证默认2分，不作为否决条件

---

### 维度五：形态验证（权重15%）

**核心指标：**
- 突破关键天机均线（5/10/20日均线）
- 或呈多头排列（均线从上至下：5>10>20>50）

**评分标准（0-5分）：**

| 评分 | 条件 |
|------|------|
| 5分 | 突破关键均线 + 缩量回踩确认 + 多头排列完好 |
| 4分 | 均线多头排列 + 价位在均线之上 |
| 3分 | 均线纠缠后向上发散 或 突破近期压力位 |
| 2分 | 均线横盘排列（无明显方向） |
| 1分 | 均线空头排列初步形成 |
| 0分 | 均线空头排列确认 + 价位在所有均线下方 |

**通过阈值：** 得分 ≥ 3分

---

### 一审综合评分

```
一审总分 = (趋势分 × 0.25) + (量能分 × 0.20) + (豪强分 × 0.20) + (邸报分 × 0.20) + (形态分 × 0.15)

通过条件：总分 ≥ 3.0 分 且 五个维度全部 ≥ 2分
否决条件：
  - 总分 < 3.0 → 驳回
  - 任一维度 = 0分 → 驳回（该维度有硬性否决权）
  - 任一维度 = 1分 + 其他维度 < 3分 → 驳回
```

---

## 二审五维审计：都察院都御史·风控审核

> 审核目标：判断入局计划的风控合规性
> 审核权限：第二道不可逆关卡，含一票否决权

### 维度一：银两调度合规（权重25%）

**核心指标：**
- 当前总调度 = Σ各商号调度 ≤ 80%
- 本商号调度 ≤ 30%

**评分标准（0-5分）：**

| 评分 | 条件 |
|------|------|
| 5分 | 总调度 ≤ 50% + 本商号 ≤ 15% |
| 4分 | 总调度 50%~65% + 本商号 15%~25% |
| 3分 | 总调度 65%~75% + 本商号 25%~30% |
| 2分 | 总调度 75%~80% + 本商号 = 30%（达上限） |
| 1分 | 总调度 > 80% 或 本商号 > 30%（超出上限）|
| 0分 | 总调度 > 90% 或 本商号 > 40%（严重超限）|

**通过阈值：** 得分 ≥ 3分

**红线标记：**
- 得分 = 1分 → 常规驳回（调整仓位后重审）
- 得分 = 0分 → 银两调度红线触发 → 立即终止

---

### 维度二：断尾求生设置（权重25%）

**核心指标：**
- 断尾位（止损位）≤ -8%
- 盈亏比 ≥ 2:1

**评分标准（0-5分）：**

| 评分 | 条件 |
|------|------|
| 5分 | 断尾 -5%~-6% + 盈亏比 > 3:1 |
| 4分 | 断尾 -6%~-7% + 盈亏比 2.5:1~3:1 |
| 3分 | 断尾 -7%~-8% + 盈亏比 2:1~2.5:1 |
| 2分 | 断尾 -8%（达上限） + 盈亏比 2:1 |
| 1分 | 断尾 -8%~-10%（略超） + 盈亏比 1.5:1~2:1 |
| 0分 | 断尾 > -10% 或 盈亏比 < 1.5:1 |

**通过阈值：** 得分 ≥ 3分

**特殊规则：**
- 强势期且强票：跟踪止盈（从最高点回撤-8%）可替代硬止损
- 弱势期：必须严格执行 -8% 硬止损，不得放宽

---

### 维度三：风险等级（权重20%）

**核心指标：**
- 商号风险等级 ≤ 中高风险
- 波动率匹配（高波动商号需低调度）

**风险等级评定规则：**

| 风险等级 | 条件 | 风险乘数 |
|---------|------|---------|
| 低风险 | 主板大蓝筹 + 帮派成熟 + 业绩稳定 | 20-30% |
| 中风险 | 主板成长股 + 帮派景气和个股基本面良好 | 10-20% |
| 中高风险 | 创业板/科创板 + 帮派景气 | 5-10% |
| 高风险 | 题材炒作 + 业绩亏损 + 次新股 | 0-5%（慎入） |

**评分标准（0-5分）：**

| 评分 | 条件 |
|------|------|
| 5分 | 低风险 + 本次调度 ≤ 20% |
| 4分 | 低风险 + 本次调度 20-30% 或 中风险 + 本次调度 ≤ 15% |
| 3分 | 中风险 + 本次调度 15-25% |
| 2分 | 中高风险 + 本次调度 ≤ 15% |
| 1分 | 中高风险 + 本次调度 > 15% |
| 0分 | 高风险 或 商号为戴罪之身(ST/*ST) |

**通过阈值：** 得分 ≥ 3分

**一票否决：**
- 得分 = 0分 → 标的红线触发（戴罪之身）→ 立即终止

---

### 维度四：大盘环境（权重15%）

**核心指标：**
- 天朝大盘（上证）未单日跌超 5%
- 非千商号跌停（跌停家数 < 1000）

**评分标准（0-5分）：**

| 评分 | 条件 |
|------|------|
| 5分 | 大盘MA20向上 + 情绪正常 + 涨家数 > 跌家数 |
| 4分 | 大盘在MA20上方横盘 + 情绪正常 |
| 3分 | 大盘在MA20附近 ±2% + 情绪正常 |
| 2分 | 大盘跌破MA20但在MA60上方 + 情绪偏弱 |
| 1分 | 大盘跌破MA60 + 单日跌幅 3-5% + 跌停家数 500-1000 |
| 0分 | 大盘单日跌幅 > 5% 或 跌停家数 > 1000 |

**通过阈值：** 得分 ≥ 3分

**一票否决：**
- 得分 = 0分 → 系统红线触发 → 全部出局，流程终止

---

### 维度五：合规红线（权重15%）

**核心指标：** 5条红线逐项检查

| 红线编号 | 红线内容 | 触发后果 |
|---------|---------|---------|
| 红线① | 戴罪之身（ST/*ST/退市整理期） | 立即否决 |
| 红线② | 近30日有朝廷问罪/财务造假 | 立即否决 |
| 红线③ | 总调度超80%或单商号超30% | 禁止入局 |
| 红线④ | 当日累计亏损达5% | 强制清仓 |
| 红线⑤ | 大盘单日跌超5%或千商号跌停 | 全部出局 |

**评分标准（0-5分）：**

| 评分 | 条件 |
|------|------|
| 5分 | 5条红线全部未触发 |
| 3分 | 1条常规违规（可调整后重审） |
| 1分 | 2条常规违规 |
| 0分 | 触发任何一条红线 |

**通过阈值：** 得分 ≥ 5分（即：5条红线必须全部未触发）

**否决处理：**
- 触发红线① → 标的红线 → 立即终止
- 触发红线② → 合规红线 → 立即终止
- 触发红线③ → 调度红线 → 禁止入局
- 触发红线④ → 亏损红线 → 强制清仓（不适用于开仓审核）
- 触发红线⑤ → 系统红线 → 全部清仓，流程终止

---

### 二审综合评分

```
二审总分 = (调度合规分 × 0.25) + (断尾求生分 × 0.25) + (风险等级分 × 0.20) + (大盘环境分 × 0.15) + (合规红线分 × 0.15)

通过条件：
  - 总分 ≥ 3.0 分
  - 合规红线得分 = 5分（无任何红线触发）
  - 断尾求生得分 ≥ 2分

否决条件：
  - 合规红线得分 < 5分（触发任何红线）→ 立即终止，最高告警
  - 总分 < 3.0 → 驳回，可调整后重审
  - 任一维度 = 0分 → 该维度特殊处理（见上）
```

---

## 三审五维审计：内阁首辅·执行审核

> 审核目标：最终复核交易指令的合理性和可行性
> 审核权限：唯一出口，批红则军令生效

### 维度一：价格合理性（权重25%）

**核心指标：**
- 建议委托价与翰林院研判的合理价位偏差 ≤ ±2%
- 不偏离当前市价 > 5%

**评分标准（0-5分）：**

| 评分 | 条件 |
|------|------|
| 5分 | 委托价 = 合理价位中心点 ±0.5% |
| 4分 | 委托价 = 合理价位 ±1% |
| 3分 | 委托价 = 合理价位 ±2% |
| 2分 | 委托价偏离合理价位 2-3% |
| 1分 | 委托价偏离合理价位 3-5% |
| 0分 | 委托价偏离 > 5%（价格极不合理） |

**通过阈值：** 得分 ≥ 3分

---

### 维度二：银两调度一致性（权重20%）

**核心指标：**
- 指令手数与户部调度方案偏差 < 5%

**评分标准（0-5分）：**

| 评分 | 条件 |
|------|------|
| 5分 | 完全一致，偏差 = 0% |
| 4分 | 偏差 < 2% |
| 3分 | 偏差 2-5% |
| 2分 | 偏差 5-10%（需说明原因） |
| 1分 | 偏差 10-20% |
| 0分 | 偏差 > 20%（严重偏离） |

**通过阈值：** 得分 ≥ 3分

---

### 维度三：策略一致性（权重20%）

**核心指标：**
- 入局/出局方向与翰林院奏折建议一致
- 风控参数与大理寺判词一致（未私自放宽）

**评分标准（0-5分）：**

| 评分 | 条件 |
|------|------|
| 5分 | 方向完全一致 + 风控参数一致 |
| 4分 | 方向一致 + 风控参数微调（<5%） |
| 3分 | 方向一致 + 风控参数调整 5-10% |
| 2分 | 方向一致 + 风控参数调整 > 10%（需说明） |
| 1分 | 方向相反（做反方向） |
| 0分 | 方向相反 + 风控完全缺失 |

**通过阈值：** 得分 ≥ 4分

---

### 维度四：执行时机（权重20%）

**核心指标：**
- 非尾盘三分钟（14:57后）
- 非集合竞价时段（09:20-09:30）
- 流动性充足（量比 > 0.5）

**评分标准（0-5分）：**

| 评分 | 条件 |
|------|------|
| 5分 | 上午时段（09:30-11:30）+ 量比 > 1.5 |
| 4分 | 上午时段 + 量比 0.8-1.5 |
| 3分 | 午盘时段（11:00-13:00）+ 量比 > 0.5 |
| 2分 | 尾盘前半段（14:00-14:55）+ 量比 > 0.5 |
| 1分 | 尾盘后半段（14:55后）|
| 0分 | 集合竞价时段 或 停牌/涨跌停无法执行 |

**通过阈值：** 得分 ≥ 3分

---

### 维度五：完整性校验（权重15%）

**核心指标：** 7个必填字段完整

| 序号 | 字段名 | 说明 |
|------|--------|------|
| 1 | 商号代码 | 6位数字 |
| 2 | 方向 | 入局/出局 |
| 3 | 价格 | 委托价（元）|
| 4 | 数量 | 手数（100的整数倍）|
| 5 | 时机 | 执行时间 |
| 6 | 有效期 | 当日/三日 |
| 7 | 断尾位 | 止损价（元）|

**评分标准（0-5分）：**

| 评分 | 条件 |
|------|------|
| 5分 | 7个字段全部完整且正确 |
| 4分 | 7个字段完整，1-2个字段格式有小瑕疵 |
| 3分 | 6个字段完整，1个字段缺失（非关键字段）|
| 2分 | 5-6个字段完整 |
| 1分 | 3-4个字段完整 |
| 0分 | 字段完整率 < 60% |

**通过阈值：** 得分 ≥ 4分（即：7个字段必须基本完整）

---

### 三审综合评分

```
三审总分 = (价格合理性分 × 0.25) + (调度一致性分 × 0.20) + (策略一致性分 × 0.20) + (执行时机分 × 0.20) + (完整性校验分 × 0.15)

通过条件：
  - 总分 ≥ 4.0 分
  - 策略一致性得分 ≥ 4分（方向不能错）
  - 完整性校验得分 ≥ 4分（字段必须完整）

否决条件：
  - 策略一致性得分 < 4分 → 驳回（方向不能错）
  - 完整性校验得分 < 4分 → 驳回（字段不完整）
  - 总分 < 4.0 → 驳回，可修改参数重审
```
