# 三审六部投资决策系统

明清官制风格的投资决策系统——仿明清官制设九司协力、三审把关，非经三道不可逆闸门，不得动用银两入局商号。

## 核心原则

- **分司决断，统归风控** — 各司独立履职，风控拥有最高权柄
- **三审闸门，批红不可逆** — 一审(御史)、二审(都御史)、三审(首辅)一旦裁定不可撤回
- **数据为凭，拒听风月** — 每项决断必须基于量化数据和标准化文书
- **红线当头，零容忍度** — 五条红线触发即止，无商量余地

## 九司架构

| Agent | 官职 | 品阶 | 职责 |
|-------|------|------|------|
| agent_01 | 锦衣卫探子 | 从七品·百户 | 情报采集（行情/指标/资金/公告） |
| agent_02 | 翰林院编修 | 正七品·编修 | 分析决策（趋势研判+买入建议） |
| agent_03 | 大理寺卿 | 正三品·卿 | 风控校验（止损/盈亏比/风险等级） |
| agent_04 | 户部主事 | 从五品·主事 | 仓位规划（凯利公式+五周期仓位） |
| agent_05 | 兵部侍郎 | 正四品·侍郎 | 指令执行（买入/卖出指令生成） |
| agent_06 | 太史令 | 从三品 | 复盘监控（持仓监控+复盘归档） |
| agent_07 | 都察院御史 | 正四品·御史 | 一审：机会审核（五维审计） |
| agent_08 | 都察院都御史 | 从二品·都御史 | 二审：风控审核（一票否决权） |
| agent_09 | 内阁首辅 | 正一品·首辅 | 三审：执行审核（唯一出口） |

## 流程

```
点将台 → 锦衣卫探马(采集) → 翰林院研判(分析) → 都察院一审 → 大理寺校勘(风控) 
→ 户部调拨(仓位) → 都察院二审 → 兵部发令(执行) → 内阁终审 → 圣旨颁布 → 太史院监修(复盘)
```

## 五条红线

1. **标的红线**：ST/退市风险/停牌股 → 立即终止
2. **合规红线**：证监会处罚/信披违规 → 立即终止
3. **调度红线**：总仓位>80% → 立即终止
4. **亏损红线**：单票亏损>-8% → 触发断尾求生
5. **系统红线**：数据缺失>30% → 暂停决策
